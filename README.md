# 🛒 E-Commerce Furniture Dashboard

This Power BI dashboard explores a furniture e-commerce dataset to uncover sales and pricing patterns.  
It highlights the performance of top-selling products, discount strategies, and customer interest by category.

### 🔍 Highlights:
- Price vs. original price analysis
- Best-selling products and tags
- Power Query used for handling missing prices
- KPIs for sales, revenue, and average discount
